# GitBoard

Расширение Chrome для доски GitHub Projects.

Родительская задача перетаскивается между колонками вместе со своими субтасками. Отдельный режим превращает её карточку в раскрывающийся список: субтаски прячутся с доски и показываются внутри родителя.

## Установка

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное» и выберите эту папку.

Откройте board-вид проекта: `github.com/orgs/…/projects/…` или `github.com/users/…/projects/…`. Доска должна быть сгруппирована по полю колонок, обычно Status.

## Как работает

Панель GitBoard в правом нижнем углу:

- **Переносить субтаски вместе с задачей.** Когда колонка родителя меняется, то же значение получает всё дерево субтасков.
- **Группировать субтаски списком.** Карточка родителя получает кнопку «Субтаски», а отдельные карточки детей скрываются.
- **Добавлять отсутствующие субтаски на доску.** Если субтаска ещё нет в проекте, расширение добавляет её и ставит в ту же колонку.
- **Обновлять доску после переноса.** Страница перезагружается, чтобы колонки совпали с сохранённым состоянием.

Запросы по умолчанию идут в `https://github.com/graphql` от текущего входа. Если сессии не хватает, в окне расширения можно сохранить fine-grained token с записью в Projects и Issues. Тогда запросы идут в `https://api.github.com/graphql`. Токен остаётся в локальном хранилище браузера.
